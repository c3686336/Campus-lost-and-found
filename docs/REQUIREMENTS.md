## 미정 사항에 적용한 시연 결정

- **보관 기간:** Stored 습득물 30일, Open 분실 신고 90일, 완료 데이터 180일. 원문에서 결정하지 않은 시연 기본값이며 관리자 설정에서 조정한다.
- **TBD 번호 오류:** REQ-9.3의 `TBD-4 days`는 부록의 매칭 기준을 가리키므로 잘못된 참조로 해석한다. 보관 일수는 별도 설정 `storedDays`를 사용한다.
- **검색 공개 시점:** 관리자 검사 후 Stored가 된 때부터 공개한다. Registered는 신고자 본인과 관리자만 조회한다.
- **매칭:** REQ-5.1~5.2의 분류·날짜 조건 및 장소/발견일 정렬을 적용한다. 유사도 점수 또는 AI 소유권 판정은 사용하지 않는다.
- **위치 구분:** 발견 장소는 공개 필드, 실제 보관 장소는 관리자 전용, 공식 반환 장소는 승인자 전용이다. 위험 물품도 승인자에게 지정된 반환 장소만 제공한다.
- **수령 장소 열람:** 일반 조회 응답에서는 승인 후에도 수령 장소·부서를 제외한다. 승인자의 확인 버튼 요청마다 열람자·시각·신청 ID를 감사 기록에 저장한다. 사고 차단 중에는 열람을 거부한다.
- **분실 신고 연결 일관성:** 같은 Open 분실 신고에 여러 대기 신청을 연결할 수 있지만 승인된 연결은 하나만 허용한다. 인도 완료 시 나머지 연결 대기 신청을 거절한다. Open 신고 철회는 허용하며 연결만 해제하므로 이후 인도가 철회를 되돌리지 않는다.
- **발생 시각:** 날짜는 필수이고 알 수 있는 시각은 선택 입력 `occurredTime`(HH:mm)으로 보관한다.
- **저장·장애:** 개별 암호화 레코드를 SQLite 트랜잭션으로 저장한다. 업무 커밋 후 백업만 실패하면 업무 성공을 유지하고 관리자에게 백업 오류와 수동 재시도를 제공한다. 조회 중 정리는 최대 1분 주기, 변경 중 정리는 즉시 적용한다.
- **위험 물품 위치 충돌:** 5.2.1의 일반 사용자 위치 비공개 문장과 4.8.3의 승인자 지정 반환 장소 공개가 충돌한다. 비공개 보관 장소는 계속 숨기고, 승인자에게만 별도 반환 장소를 보여주는 REQ-8.2를 적용한다.
- **오인도 차단 범위:** 4.7.2 설명의 모든 후속 동작 차단과 REQ-7.5의 비관리자 후속 동작 차단이 다르다. 관리자의 사고 해결 작업을 허용하고 일반 사용자 조작을 차단하는 REQ-7.5를 적용한다.
- **검색 제거 시점:** 3.1의 매칭된 물품 숨김은 단순 후보 생성 시점이 아닌 소유권 확인 및 인도 흐름에 적용한다. 후보만 생겨도 숨기면 REQ-5.5와 충돌하므로, 공개 검색은 REQ-4.2 상태 규칙을 사용하고 반환 완료 시 REQ-7.4대로 제거한다.
- **알림:** 앱 내부 알림으로 제공한다. 실제 이메일·푸시 발송은 외부 서비스 연동 범위다.
- **신원 확인:** 데모 로그인 확인을 교체 가능한 제공자로 추상화한다. 물품 소유권 심사는 별개로 관리자가 수행한다.
- **PWA 오프라인:** 화면 자원만 캐시한다. 계정·신고·증빙·API 응답은 캐시하지 않으며 오프라인 변경을 성공으로 표시하지 않는다.
- **부하 검증:** 격리된 임시 데이터베이스를 사용한 로컬 API 동시 요청의 성공률과 p50/p95를 측정한다. 실사용자 1% 부하나 학기 운영을 대체하는 시연 측정이며 운영 SLA 증거로 해석하지 않는다.
